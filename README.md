# di-framework/cli-extensions

Installable `di-framework` command groups. First-party plugin: `@di-framework/di-framework-cli-plugin-platform` (`di-framework extensions install platform`). Community plugins use the same `di-framework-cli-plugin-<name>` name shape.

This tree is a bun workspace stub for the v6 split ([#485](https://github.com/di-framework/di-framework/issues/485)). Plugin source moves here in the extract issue.
